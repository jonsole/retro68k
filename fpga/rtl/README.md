# FPGA RTL

Plain Verilog-2005. Simulated with Icarus Verilog in `sim/`.

Written (phase 2, version 1):

| File | What | Spec |
|------|------|------|
| `retro68k.v` | The computer without board parts: wires everything below together; reset logic | 7 |
| `timebase.v` | 100 MHz phase counters: position in the 50 ns grid and in the 100 ns slot | 1, 5 |
| `cpu_fx68k.v` | fx68k at 40 MHz with alternating phase enables (a 20 MHz 68000) | 1 |
| `bus_if.v` | 68000 bus interface: fixed-point clock crossing, decoding, early /DTACK, posted writes, bus errors, 16-bit-halves register rules | 1, 3 |
| `sram_ctl.v` | SRAM controller: 5 memory cycles per slot, cycle 0 for the CPU | 5 |
| `bootrom.v` | 32 KB boot ROM in block RAM | 7 |
| `sysregs.v` | System control registers (no I2C yet) | 7 |
| `serial.v` | USB serial: FT232H async FIFO interface, 2 KB FIFOs, control commands | 14 |
| `fifo8.v` | Byte FIFO in block RAM | |
| `regmap.vh` | Register addresses, generated by `tools/regmap.py`; do not edit | 3 |
| `platform/sim/oddr.v` | Behavioural DDR output register | |

Still to come: interrupt controller, timers, video, sprites, copper, audio, DMA engine, SD card, keyboard, I2C, `platform/artix7/` (MMCMs, OSERDESE2, ODDR, pads) and `top_ks3.v` (the KS3 pin-level top).

fx68k itself is a git submodule in `fpga/third_party/fx68k` (GPL-3.0).
