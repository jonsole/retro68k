# FPGA RTL

Planned modules (see the specs in `docs/spec/`):

- `bus_if.v` – fx68k bus interface: decode, `/DTACK`, interrupts, reset (spec 1)
- `sram_ctl.v` – SRAM controller and memory-cycle scheduler (spec 5)
- `video.v` – timing, layers, palette, text mode; `sprites.v`; `copper.v` (specs 4, 9, 10)
- `audio.v` – sample channels, stream, mixer, sigma-delta output (spec 6)
- `dmx.v` – DMA engine and blitter (spec 11)
- system blocks: timers, interrupts, serial, SD card, keyboard, I2C (specs 7, 12–16)
- `platform/artix7/` – MMCMs, OSERDESE2, ODDR, block RAM and pad wrappers
- `top_ks3.v` – pin-level top module for the KS3
- `regmap.vh` – generated by `tools/regmap.py`; do not edit
